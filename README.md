# Saumon Fumé des Acacias — site vitrine

Site statique, sans installation. Ouvrir `index.html` dans un navigateur.

## Mise en ligne avec GitHub Pages
1. Créer un dépôt et y envoyer tout le contenu de ce dossier (index.html à la racine).
2. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Le site est publié à l'adresse indiquée par GitHub après une minute environ.

## Contenu
- `index.html` : le site (toutes les pages)
- `support.js` : moteur d'affichage (ne pas supprimer)
- `img/` : photos (webp)
- `uploads/` : logo, poisson doré, étiquettes produits, police Sunset Gothic Pro
